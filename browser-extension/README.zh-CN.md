# 49 ChatGPT Copy Fix

实验性配套工具，尚未完成独立的浏览器到 Obsidian 全流程验证。当前版本接受剩余网页格式差异，不要求安装本扩展；它不会随 Obsidian 插件自动启用。

ChatGPT 网页的复制按钮可能在输出时去掉加粗标记、卡片结构和图形；这些信息丢失后，Obsidian 无法可靠推断回来。这个配套扩展从当前回答的实际显示结构复制，再交给统一 Obsidian 插件处理。

安装后照常点击回答下的“复制”，或选中文字后 Ctrl+C，不增加日常步骤。

作用范围仅为 `https://chatgpt.com/*`。权限仅为 `clipboardWrite`：只在用户主动复制时写入剪贴板；不读取剪贴板，不请求网络，不保存回答，不访问其他网站。

构建后的文件夹为 `49-chatgpt-copy-fix`，可在 Chrome 或 Edge 的扩展管理页面通过“加载已解压的扩展程序”安装。此扩展不会由 Obsidian 插件自动安装。
